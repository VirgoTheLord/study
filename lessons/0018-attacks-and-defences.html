CAPTCHA ("prove you're human") protects against automated, scripted attacks (bots), e.g. mass account creation or password guessing.

Firewalls

A firewall filters network traffic between a trusted and an untrusted network using rules. Types: packet filter (looks at addresses/ports of each packet), stateful firewall (also tracks the state of TCP/IP connections, so it can accept replies to connections you started), application/proxy firewall (understands application protocols).

TermMeaning
Ingress filteringFilter traffic coming in: malicious traffic prevention
Egress filteringFilter traffic going out: data leakage prevention
NATTranslates private addresses to public ones: hides the identity of internal systems
Stateful inspectionTracks connection state

A firewall protects a network from network threats such as scanning and unwanted connections. It cannot stop dumpster diving, shoulder surfing or physical theft.

Secure protocols

  • TLS/SSL: encrypts traffic between a client and server. HTTPS = HTTP over TLS.
  • SFTP = file transfer over SSH (encrypted). SNMPv3 adds authentication and encryption to SNMP.
  • DNSSEC adds digital signatures to DNS records so you can verify they are authentic and unaltered. It provides integrity and authenticity, not encryption; the data is still readable.
  • IPSec secures traffic at the IP layer. Two protocols and two modes:
Transport modeTunnel mode
AH (Authentication Header): integrity and authentication, no encryptionProtects the payload; original IP header stays visibleAuthenticates the whole original packet inside a new outer IP header
ESP (Encapsulating Security Payload): encryption plus integrityEncrypts only the payload; original IP addresses visibleEncrypts the entire original packet, wrapped in a new IP header. Hides the private addresses. Used for site-to-site VPNs.
Worked example (2025 question)

Requirements: two offices, full confidentiality and integrity, and the private IP addresses used inside must also be hidden. Confidentiality needs encryption, so ESP (AH doesn't encrypt). Hiding the inner IP addresses means wrapping the entire original packet, which is tunnel mode. Answer: ESP in tunnel mode.

Check yourself

ISRO 2025 · Q36

A company wants to transmit data between its two offices with full confidentiality and integrity. Private IP addresses used by systems inside the company should also be confidential. Which IPSec configuration meets the requirements?

ESP encrypts; tunnel mode hides the inner packet including private addresses.
ISRO 2025 · Q11

In which of the following cases is a user persuaded to reveal personal data by hackers/cyber criminals?

Phishing deceives the person into giving away data.
ISRO 2025 · Q12

Which of the following protocols/applications does not facilitate data encryption when data is sent over a computer network using that protocol/application?

DNSSEC only signs records.
ISRO 2025 · Q14

Which of the following can be protected using a firewall?

Only the network-based threat is blocked by a firewall.
ISRO 2023 · Q72

Match: (i) Encryption (ii) MAC Cloning (iii) ARP Spoofing (iv) Fingerprinting with (P) manipulation of identification of a host (through NIC identifier) (Q) determining version and name of OS and OS utilities (R) protecting the confidentiality (S) poisoning the IP to MAC address mapping.

Encryption → confidentiality (R); MAC cloning → manipulating a host's identifier (P); ARP spoofing → poisoning IP-to-MAC mapping (S); fingerprinting → OS detection (Q).
ISRO 2023 · Q73

Match: (i) Ingress filtering (ii) Egress filtering (iii) NAT (iv) Stateful firewall with (P) data leakage prevention (Q) hiding identity of systems (R) keep track of TCP/IP connections (S) malicious traffic prevention.

Ingress → S; egress → P; NAT → Q; stateful → R.
ISRO 2023 · Q71

Which of the following is the cause of the Ping of Death issue related to ICMP packets?

An oversized packet overflows the receiver's buffer.
