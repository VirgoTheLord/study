27 · Linear Algebra & Calculus

Module H · MathsAsked in 2023 and 2025 Matrices, determinants, eigenvalues and simple integrals.

Start here: what is a matrix?

A matrix is a rectangular grid of numbers. An m × n matrix has m rows and n columns. A square matrix has the same number of rows and columns. The identity matrix I has 1s on the diagonal and 0s elsewhere. The transpose Aᵀ swaps rows and columns. Multiplying matrices: (m×n) times (n×p) gives (m×p); each entry is a row of the first dotted with a column of the second.

Determinants

The determinant det(A) is a single number computed from a square matrix. It tells you whether the matrix is invertible: det ≠ 0 ⇔ invertible; det = 0 means "singular".

  • 2×2: det [[a, b],[c, d]] = ad − bc.
  • 3×3: expand along a row or column (cofactor expansion): det = a₁₁(a₂₂a₃₃ − a₂₃a₃₂) − a₁₂(a₂₁a₃₃ − a₂₃a₃₁) + a₁₃(a₂₁a₃₂ − a₂₂a₃₁). Choose the row or column with the most zeros to save work.
Worked example

det [[2, 3],[4, 5]] = 2·5 − 3·4 = −2.

Time-saving properties (look for these before computing anything):
• A row (or column) of all zeros → det = 0.
• Two identical or proportional rows/columns → det = 0.
• A row that is a sum or multiple of other rows → det = 0.
• Triangular or diagonal matrix → det = product of the diagonal entries.
• Swapping two rows → det changes sign. Multiplying a row by k → det multiplies by k.
• det(AB) = det(A) det(B); det(Aᵀ) = det(A); for an n×n matrix det(kA) = kⁿ det(A).

Questions that give a 4×4 matrix of "nice" numbers often hide a dependency between rows (e.g. row 3 = row 1 + row 2), making the determinant 0. Try subtracting rows from each other first.

Eigenvalues and eigenvectors

A nonzero vector v is an eigenvector of A with eigenvalue λ if A v = λ v: the matrix just stretches v by λ without turning it. Find eigenvalues by solving the characteristic equation det(A − λI) = 0.

  • For an n×n matrix there are n eigenvalues (counting repeats).
  • Sum of eigenvalues = trace (the sum of the diagonal). Product of eigenvalues = det(A).
  • For a triangular matrix (all zeros above or below the diagonal), the eigenvalues are simply the diagonal entries.
  • A matrix is singular exactly when 0 is one of its eigenvalues.
Worked example: a matrix with a zero-heavy first column

A = [[4, 3, 1],[0, 6, 0],[0, 4, 7]]. Expand det(A − λI) along the first column (only the top entry is non-zero): (4 − λ) × det [[6 − λ, 0],[4, 7 − λ]] = (4 − λ)(6 − λ)(7 − λ). So the eigenvalues are 4, 6, 7, and the smallest is 4. Check with the properties: trace = 17 = 4 + 6 + 7 ✓.

When a matrix is given in a PDF, take care to read the rows in the right order: swapping row order changes which entries sit in the zero-heavy column and therefore the answer.

Integrals

A definite integral ∫ₐᵇ f(x) dx is the area under f between a and b. Useful rules: ∫ xⁿ dx = xⁿ⁺¹/(n+1) (for n ≠ −1), so ∫₀¹ x² dx = 1/3.

For a multiple (double or triple) integral over a box with constant limits, when the integrand factors into pieces that each depend on one variable, integrate each piece on its own and multiply:

Worked example

∫₀¹ ∫₀² ∫₀³ x y z dz dy dx = (∫₀¹ x dx)(∫₀² y dy)(∫₀³ z dz) = (1/2)(2)(9/2) = 9/2.

Symmetry shortcut: an odd function (f(−x) = −f(x), like x, x³) integrated over a symmetric interval [−a, a] gives 0. An even function (x², x⁴) gives twice the integral over [0, a]. In a triple integral, if one factor is odd and its interval is symmetric, the whole integral is 0.
