14 · The Data Link Layer: Errors, Flow Control, Ethernet

Module D · Computer networksAsked in 2023 and 2025 Error detection and correction, Hamming distance, CRC, CSMA/CD, Wi-Fi speeds.

Start here

The data link layer moves frames between two directly connected devices. Wires and radio are noisy, so bits sometimes flip. Two jobs follow: detect that a frame was damaged, or even correct it. And when many devices share one cable, rules are needed to avoid talking over one another.

Error detection

Idea: add a few extra bits (redundancy) computed from the data. The receiver recomputes them; a mismatch means an error.

Parity

Add one bit so the total count of 1s is even (even parity) or odd (odd parity). Data 1011001 has four 1s, so even parity adds 0; data 1011011 has five 1s, so even parity adds 1. It detects any odd number of flipped bits but misses two flips (the count stays even), and it can't tell which bit flipped.

Checksum

Add up the data words and send the sum (internet checksum is a 16-bit one's complement sum). The receiver adds everything including the checksum. Cheap, but weaker than CRC.

CRC (cyclic redundancy check)

Treat the data as a binary polynomial and divide it by a fixed generator using XOR (no carries). Send the remainder; the receiver divides and expects remainder 0. It detects all single and double errors and all burst errors shorter than the generator. It detects but does not correct.

Worked example

Data 1101011011, generator 10011 (degree 4, so append 4 zeros): 11010110110000. Long-divide with XOR by 10011 at each leading 1. The remainder is 1110. The sender transmits 1101011011 1110.

Error correction and Hamming distance

The Hamming distance between two equal-length bit strings = the number of positions where they differ. 01000 and 00000 differ in 1 position (distance 1). The minimum distance d of a code is the smallest distance between any two valid codewords.

A code with minimum distance d can detect up to d − 1 bit errors and correct up to ⌊(d − 1)/2⌋.

To correct, the receiver picks the valid codeword nearest to what arrived. If two codewords are equally near, the error cannot be corrected.

Worked example (2025 question)

Valid codewords: A = 00000, B = 01110, C = 11000. Received: 01000. Distance to A = 1 (one bit differs). To B: 01000 vs 01110 differ in 2 places. To C: 01000 vs 11000 differ in 1 place. A and C tie at distance 1, so the system cannot decide: unable to correct.

Which codes correct errors? Hamming codes, Reed–Solomon codes, LDPC (low-density parity-check) and convolutional codes are error-correcting. Parity, checksums and CRC are error-detecting only.

Hamming code: for m data bits you need r check bits with 2ʳ ≥ m + r + 1; check bits sit at positions 1, 2, 4, 8, … Each check bit covers a set of positions, and the pattern of failed checks spells out the position of the single bad bit.

Flow control and ARQ

  • Stop-and-wait: send one frame, wait for its acknowledgement (ACK), repeat. Simple but wasteful on long links.
  • Sliding window: allow W frames outstanding at once. Go-Back-N: on an error, resend from the lost frame onward. Selective Repeat: resend only the lost frame.

Sharing a medium: MAC protocols

ALOHA: send whenever you like and hope for no collision (poor efficiency). CSMA: listen first, send if quiet. CSMA/CD (Ethernet, wired): listen first, and while sending keep listening for collisions (collision detection); on a collision, stop and retry after a random wait. CSMA/CA (Wi-Fi) avoids collisions instead of detecting them.

Why Ethernet has a minimum frame size

A sender must still be transmitting when news of a collision reaches it from the far end. A signal takes time Tp to cross the cable and the collision signal Tp to return, so the frame must last at least 2·Tp:

Minimum frame transmission time ≥ 2 × Tp, so minimum frame size = 2 × Tp × bandwidth.

Worked example (2023 question)

Minimum frame 1500 bytes = 12,000 bits. Cable 1 km, signal speed 250,000 km/s: Tp = 1 / 250,000 s = 4 µs, so 2Tp = 8 µs. Bandwidth = frame size ÷ 2Tp = 12,000 bits ÷ 8 µs = 1.5 × 10⁹ = 1.5 Gbps.

Check yourself

ISRO 2023 · Q13

In a computer network using CSMA/CD, the minimum frame size for data transfer is 1500 bytes. What will be the data transfer speed in this network over 1 km cable, if the signal speed in the cable is 250000 km/sec and no repeaters are used?

Tp = 4 µs, 2Tp = 8 µs, frame = 12,000 bits → 1.5 Gbps.
ISRO 2025 · Q37

A communication system uses the three 5-bit words A: 00000, B: 01110, C: 11000 as the only valid codewords, with error correction using Hamming distance. The receiver gets 01000. What would the system conclude?

A and C are both at distance 1, B at distance 2. A tie means correction is impossible.
ISRO 2023 · Q16

Which of the following is true?

Parity and CRC only detect. Reed–Solomon and LDPC correct.
ISRO 2023 · Q22

Which of the following methods is used to detect double errors?

A single parity bit misses two flipped bits (the parity stays the same). CRC detects double errors. A plain XOR checksum can miss two flips in the same bit position.
ISRO 2023 · Q15

Match 802.11 versions with speeds: (i) 802.11ac (ii) 802.11 a/g (iii) 802.11 ad (iv) 802.11 b with (P) 7 Gbps (Q) 11 Mbps (R) 54 Mbps (S) 3.5 Gbps.

ac = 3.5 Gbps, a/g = 54 Mbps, ad = 7 Gbps, b = 11 Mbps.
