23 · Combinational Circuits: Adders, Mux, Decoders

Module G · Digital logicAsked in 2023 and 2025 Circuits whose output depends only on the present inputs.

Start here

A combinational circuit has no memory: its outputs are a function of its current inputs only (a calculator's adder, for example). Contrast with sequential circuits (next lesson) which remember past values. A few standard building blocks cover almost every exam question.

Adders

Adding two bits: 0+0=0, 0+1=1, 1+1=10 (sum 0, carry 1).

CircuitInputsOutputsEquations
Half adderA, B (2)Sum, Carry (2)Sum = A ⊕ B; Carry = A·B
Full adderA, B, Carry-in (3)Sum, Carry-out (2)Sum = A ⊕ B ⊕ Cin; Cout = AB + Cin(A ⊕ B)

A half adder can't accept a carry from a previous column, so to add multi-bit numbers you chain full adders: the carry-out of each feeds the carry-in of the next (a ripple-carry adder). The full adder needs three inputs and gives two outputs.

Worked example: 1 + 1 + 1 (full adder)

A = 1, B = 1, Cin = 1. Sum = 1⊕1⊕1 = 1. Carry-out = 1 (since 1+1+1 = 3 = binary 11).

Multiplexer and demultiplexer

A multiplexer (mux) chooses one of many inputs and sends it to the single output, like a railway switch. The select lines choose which. With n select lines you can choose among 2ⁿ inputs: a 4-to-1 mux has 2 select lines, an 8-to-1 mux has 3.

A demultiplexer (demux) does the reverse: one input is routed to one of many outputs. A 1-to-16 demux needs 4 select lines (2⁴ = 16).

Decoders and encoders

  • A decoder turns an n-bit binary code into a 1-of-2ⁿ output: exactly one output line goes high. A 3-to-8 decoder has 3 inputs and 8 outputs. Used for address decoding.
  • An encoder does the opposite: 2ⁿ input lines (one active) → n-bit code. An octal-to-binary encoder has 8 inputs and 3 outputs and needs 3 OR gates (one per output bit), not 8.
Worked example: building a big decoder from small ones (2025 question)

You want a 1-of-32 decoder (5 inputs) using 3-to-8 decoders (3 inputs, 8 outputs). 32 ÷ 8 = 4 decoders of 3-to-8 produce the 32 outputs. A fifth small component (a 2-to-4 decoder) uses the two extra input bits to enable exactly one of the four. The question asks only for the 3-to-8 ones: 4.

Check yourself

ISRO 2023 · Q37

A full adder circuit requires

Inputs A, B, Cin; outputs Sum and Cout. Two inputs and two outputs would be a half adder.
ISRO 2023 · Q35

Which of the following definitions is true? (i) A digital multiplexer takes one input from many inputs and outputs the selected one. (ii) Four select lines are required for a 1-16 demultiplexer. (iii) Eight OR gates are required to implement an octal to binary encoder.

(i) true. (ii) true: 2⁴ = 16. (iii) false: an octal-to-binary encoder needs 3 OR gates (one per output bit).
ISRO 2025 · Q50

How many 3 to 8 line decoders are required for a 1 of 32 decoder?

32 outputs ÷ 8 outputs per decoder = 4.
Practice (written by me)

How many select lines does an 8-to-1 multiplexer need?

2³ = 8, so 3 select lines.
