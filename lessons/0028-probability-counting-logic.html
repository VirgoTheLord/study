Probability

Probability measures how likely an event is, from 0 (impossible) to 1 (certain). When all outcomes are equally likely: P(E) = favourable outcomes ÷ total outcomes.

Worked example (2023)

A bag has 6 blue, 5 white and 4 yellow balls (15 in all). P(not white) = non-white ÷ total = (6 + 4) ÷ 15 = 10/15 = 2/3. Or use the complement rule: 1 − P(white) = 1 − 5/15 = 2/3.

Rules
• Complement: P(not E) = 1 − P(E).
• Addition: P(A or B) = P(A) + P(B) − P(A and B). For mutually exclusive events the last term is 0.
• Independent events: P(A and B) = P(A) × P(B).
• Conditional: P(A | B) = P(A and B) ÷ P(B).
• Bayes: P(A | B) = P(B | A) × P(A) ÷ P(B).

Random variables and standard distributions

A random variable is a number produced by a random experiment (the number rolled on a die; the waiting time for a bus). A discrete random variable takes separate values (0, 1, 2, …) and is described by a probability mass function. A continuous one takes any value in a range and is described by a probability density function.

So the standard distribution that applies to discrete random variables, among Gaussian, Poisson, Rayleigh and Exponential, is the Poisson distribution (2025 Q86). For a binomial with n trials and success probability p: mean = np, variance = np(1 − p). For a Poisson with rate λ: mean = variance = λ.

Worked example (2025): letters of GAGANYAAN with no repetition

The word has 9 letters but only four different letters: G, A, N, Y. "No repetition of a letter" means each letter can appear at most once in the new word, so a four-letter word uses G, A, N, Y once each. Number of arrangements = 4! = 24. (3024 = 9×8×7×6 would wrongly treat the repeated letters as different.)

Worked example (2025): subsets with no two consecutive numbers

Let s(n) = number of such subsets of {1, …, n}. Take the largest element, n. Either n is not in the subset (s(n−1) ways), or it is, and then n−1 cannot be (s(n−2) ways). So s(n) = s(n−1) + s(n−2): the Fibonacci rule. Start: s(0) = 1 (the empty set), s(1) = 2. Then s(2) = 3, s(3) = 5, s(4) = 8, s(5) = 13, s(6) = 21, s(7) = 34, s(8) = 55, s(9) = 89, s(10) = 144, s(11) = 233, s(12) = 377.

Propositional logic

A proposition is a statement that is true or false. Connectives: ¬ (not), ∧ (and), ∨ (or), → (implies), ↔ (if and only if). The one to master is implication:

p → q ≡ ¬p ∨ q. (An implication is false only when the "if" is true and the "then" is false.) De Morgan: ¬(p ∧ q) ≡ ¬p ∨ ¬q; ¬(p ∨ q) ≡ ¬p ∧ ¬q. The contrapositive ¬q → ¬p is equivalent to p → q; the converse q → p is not.

Worked example (2025)

"If the vehicle is powered ON (q) and power is available to the avionics (p), then communication will be established (r)": (p ∧ q) → r. Replace A → B by ¬A ∨ B: ¬(p ∧ q) ∨ r. Apply De Morgan: ¬p ∨ ¬q ∨ r.

First-order logic adds variables, predicates and the quantifiers ∀ (for all) and ∃ (there exists). Its connectives are the same ones: ¬ ∧ ∨ → ↔.

Sets

  • |A| is the number of elements. A set with m elements has 2ᵐ subsets (its power set).
  • Cartesian product A × B = all ordered pairs (a, b); |A × B| = |A| · |B|. The n-fold product Aⁿ = all ordered n-tuples from A has mⁿ elements when |A| = m.
  • |A ∪ B| = |A| + |B| − |A ∩ B| (inclusion–exclusion).
  • Relations on A (subsets of A × A): 2^(m²). Functions from A to B: |B|^|A|.
