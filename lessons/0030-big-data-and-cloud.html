30 · Big Data, Cloud Computing & Virtualization

Module I · AI and dataAsked in 2023 and 2025 Mostly vocabulary: learn each term once and the marks are easy.

Big Data

Big Data means datasets so large, fast or varied that ordinary single-machine databases can't handle them. They are described by the "Vs":

VMeaning
VolumeHow much data
VelocityHow fast it arrives and must be processed
VarietyMany formats: tables, text, images, video
VeracityHow trustworthy/clean it is
ValueUsefulness of what you extract

"Visualisation" is not one of the Vs (it is a way of presenting results).

Types of data

TypeMeaningExamples
StructuredFixed format, fits rows and columnsRelational tables
Semi-structuredHas tags/keys but flexible shapeXML, JSON
UnstructuredNo predefined formatText files, images, videos

Hadoop, HDFS and friends

  • Hadoop is a framework for storing and processing big data across clusters of ordinary machines.
  • HDFS (Hadoop Distributed File System): its primary purpose is to store very large files across multiple machines. Files are split into big blocks, spread over many DataNodes and copied (replicated) for fault tolerance; a NameNode keeps the directory of where blocks are. It is built for write-once, read-many access and high throughput, accepting high latency. So HDFS is a poor fit for: many simultaneous writes to the same file, many small files, or applications needing low-latency access.
  • MapReduce: batch processing in two steps: map (process pieces in parallel) then reduce (combine results).
  • Stream processing (continuous, real-time): Apache Flink, Spark Streaming, Storm, Kafka. Hadoop itself is batch. Splunk analyses machine/log data. ERDPlus is just a tool for drawing ER diagrams.
  • NoSQL databases store unstructured and semi-structured data and scale out (see lesson 21). Cassandra is a distributed NoSQL store. An in-memory database keeps data in RAM for speed.

Cloud computing

Cloud computing means renting computing resources (servers, storage, software) over the Internet on demand and paying for what you use, instead of owning hardware.

Service modelYou get…Example
IaaS (Infrastructure)Virtual machines, storage, networksAmazon EC2
PaaS (Platform)A ready runtime to deploy your codeGoogle App Engine
SaaS (Software)A finished applicationGmail, Office 365
Deployment modelMeaning
PublicOwned by a provider, shared by many customers over the Internet
PrivateUsed by a single organisation, within its own premises (or dedicated)
HybridA mix of private and public clouds
CommunityShared by organisations with common concerns
  • Elasticity: the ability to scale resources up and down automatically as demand changes. (Scalability is the ability to grow; elasticity is growing and shrinking on demand.)
  • Cloud bursting: when load spikes beyond what a private cloud can handle, temporarily renting extra capacity from a public cloud.

Virtualization

Virtualization lets one physical machine run several virtual machines (VMs), each with its own operating system, as if they were separate computers. The software that creates and manages them is the hypervisor (virtual machine monitor).

  • Full virtualization: the guest OS runs unmodified, believing it has real hardware.
  • Para-virtualization: the guest OS is modified to cooperate with the hypervisor (faster, but needs a changed OS).
  • Dual boot is different: two OSs installed on the same machine, but you boot only one at a time. Virtualization lets multiple OSs run simultaneously.
  • Containers (Docker) share the host's kernel and are lighter than full VMs.
  • JMX (Java Management Extensions) is the standard Java API for monitoring and managing applications.

Check yourself

ISRO 2025 · Q22

With respect to hypervisors: (P) Runs on host machine physical hardware, (Q) Hosted hypervisor, (R) Runs on the operating system of physical host machine, (S) Bare metal hypervisor. Which is the correct match?

Type 1 = bare metal, on the hardware (P, S). Type 2 = hosted, on an OS (Q, R).
ISRO 2025 · Q24

What is the primary purpose of Hadoop Distributed File System (HDFS) in Big Data storage?

That is exactly what HDFS is for.
ISRO 2025 · Q23

Which of the following is not a characteristic of Big Data?

Volume, Velocity, Variety (and Veracity, Value).
ISRO 2025 · Q25

Which of the following is a Big Data tool employed for real-time stream processing?

Flink is a stream processor. Hadoop is batch-oriented.
ISRO 2025 · Q26 and Q27

Which is used for storing unstructured data in a Big Data environment, and how do you match structured / semi-structured / unstructured with (Q) fixed format, (R) XML, JSON, (P) text, images, video?

NoSQL stores unstructured data. Structured = fixed format (Q); semi-structured = XML/JSON (R); unstructured = text, images, video (P).
ISRO 2023 · Q63

Which scenario may not be a good fit for HDFS?

Practice version. HDFS favours throughput over latency, so low-latency access (and multiple simultaneous writers to one file) is where it fits poorly. The 2023 paper's wording was hard to read in the extracted text, so I phrased this check myself.
ISRO 2025 · Q21

What does "elasticity" in cloud computing refer to?

Elasticity = scale out and in automatically with demand.
