22 · Boolean Algebra, Logic Gates & K-Maps

Module G · Digital logicAsked in 2023 and 2025 The language of digital circuits and how to simplify it.

Start here

A computer's circuits work with two voltage levels, treated as 0 (false/low) and 1 (true/high). Boolean algebra is the maths of 0s and 1s. A logic gate is a tiny circuit that computes a Boolean function of its inputs.

  • NOT (A′ or Ā) flips the input. AND: 1 only if all inputs are 1. OR: 1 if any input is 1. NAND = NOT AND; NOR = NOT OR.
  • XOR: output 1 when the inputs are different. So it outputs 0 when both inputs are 1 or both are 0. XNOR: 1 when the inputs are the same.
  • NAND and NOR are universal gates: any circuit can be built from just one of them. If you tie both inputs of a NAND (or NOR) together, A·A = A, so the output is NOT A: a NOT gate.
Worked example: both inputs tied together

NAND with inputs A and A: output = (A·A)′ = A′. NOR with inputs A and A: (A+A)′ = A′. Both give a NOT gate.

A truth table for n input variables has 2ⁿ rows.

Forms of a function

  • A minterm is an AND of all variables (each plain or complemented) that is 1 for exactly one input row. A sum of products (SOP) ORs the minterms where the function is 1. Example: X′Y′Z′ + X′YZ′.
  • A maxterm is an OR of all variables that is 0 for exactly one row; a product of sums (POS) ANDs the maxterms where the function is 0.

Simplifying with a Karnaugh map (K-map)

A K-map is the truth table redrawn as a grid so that neighbouring cells differ in exactly one variable. This makes simplification a visual job. For 3 variables the grid has 8 cells (2 × 4). The key trick: label the rows/columns in Gray code (00, 01, 11, 10), not in binary order, so that adjacent cells differ by one bit.

  1. Mark a 1 in every cell where the function is 1.
  2. Circle groups of 1s. Group sizes must be powers of 2 (1, 2, 4, 8). Groups may wrap around the edges.
  3. Make groups as big as possible, and cover every 1 at least once.
  4. Each group becomes one product term: keep the variables that do not change across the group, drop those that do.
  5. OR the terms together.
Worked example (2025 question): X′Y′Z′ + X′YZ′

Both terms contain X′ and Z′. The only variable that differs is Y (once Y′, once Y). By the rule A·Y′ + A·Y = A, we get X′Z′.

On the map with rows labelled X′Y′, X′Y, XY, XY′ and columns Z′, Z, the 1s sit in the Z′ column in the rows X′Y′ and X′Y. These two adjacent cells form a group of 2, which simplifies to X′Z′. So the correct K-map is the one with 1s in the (X′Y′, Z′) and (X′Y, Z′) cells and 0 elsewhere.

ISRO 2025 · Q52

The Boolean expression is X′Y′Z′ + X′YZ′. Which K-map represents it? (Rows X′Y′, X′Y, XY, XY′; columns Z′, Z.)

Both terms contain Z′ and X′, so the 1s are in the Z′ column, in the two rows that start with X′ (X′Y′ and X′Y). Option 4 would be only one of the two terms.
Practice (written by me)

Simplify A·B + A·B′.

A·B + A·B′ = A(B + B′) = A · 1 = A.
