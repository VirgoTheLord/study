13 · Network Basics & the Layered Model

Module D · Computer networksAsked in 2023 and 2025 What a network is, the layers, the devices, delays, and application protocols.

Start here

A computer network is a set of devices (hosts) that exchange data over links. Sending a file across the world involves cables, wireless links, routers, error handling, addressing, and applications. To keep this manageable, the problem is split into layers. Each layer does one job and relies only on the layer below it, like a postal system: you write a letter (application), put it in an envelope (adds an address), the post office sorts it (routing), trucks carry it (physical).

Switching: how data travels

  • Circuit switching: a dedicated path is reserved for the whole call (old telephone network).
  • Packet switching: data is cut into packets, each sent independently and reassembled at the destination (the Internet). Shares links efficiently.

The Internet's TCP/IP model merges the top three into one Application layer and the bottom two into Link, giving four layers: Application, Transport, Internet, Link.

Encapsulation

As data goes down the layers at the sender, each layer adds its own header in front (and the link layer a trailer too). At the receiver each layer strips its header. The extra bytes are overhead.

Worked example: header overhead (2023 question)

A message of 270 bytes passes through 5 layers; each adds a 6-byte header. Total headers = 5 × 6 = 30 bytes. Total sent = 270 + 30 = 300 bytes. Fraction wasted = 30 / 300 = 10%.

Troubleshooting tip: a wrong default gateway setting means the host can't reach anything outside its own network. Routing and logical addressing belong to Layer 3, so it's a network layer problem.

Delays and speed (you'll need these soon)

Transmission delay = packet size ÷ bandwidth (time to push all bits onto the wire)
Propagation delay = distance ÷ signal speed (time for a bit to travel)
Round-trip time (RTT) ≈ 2 × propagation delay (+ queuing and processing)
Units: 1 Gbps = 10⁹ bits per second; 1 byte = 8 bits.

Check yourself

ISRO 2025 · Q35

While troubleshooting an Internet access problem reported by a user, a computer technician finds that the default gateway setting is wrong. Which layer of the OSI model is associated with the cause of the problem?

Gateways and IP routing belong to the network layer, Layer 3.
ISRO 2023 · Q14

For internal data communication through a computer network, a 5-layer protocol hierarchy is proposed. Applications generate 270-byte messages. At each layer a 6-byte header is added. What fraction of network bandwidth (in %) is wasted due to headers?

30 header bytes out of 300 total = 10%. Dividing by 270 instead of 300 would give 11%, which is not an option; always divide by the total sent.
Practice (written by me)

Which device forwards frames using MAC addresses and sends them only to the destination port?

A switch learns which MAC address is on which port. A hub repeats to every port; a router works with IP addresses.
