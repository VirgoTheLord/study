29 · Artificial Intelligence & Machine Learning

Module I · AI and dataAsked in 2023 and 2025 Agents, search, logic, and the main learning methods.

Start here

Artificial intelligence (AI) is making machines do things that normally need human intelligence: understanding language, recognising images, planning, deciding. Machine learning (ML) is the part of AI where the machine learns patterns from data instead of being explicitly programmed. Exams ask you for the standard names and what each one is for. Learn them as small, separate facts.

Intelligent agents

An agent perceives its environment through sensors and acts on it through actuators (a thermostat, a self-driving car, a chess program). The standard types, in increasing sophistication:

TypeHow it decides
Simple reflexRule: "if percept then action". No memory.
Model-based reflexKeeps an internal model of the world so it can handle things it can't see right now.
Goal-basedChooses actions that achieve a stated goal (uses search/planning).
Utility-basedPicks the action with the best "happiness" score when several routes reach the goal.
Learning agentImproves its own performance from experience.

"Unity-based" is not an agent type (Unity is a game engine).

Search and optimisation

Many AI problems are search: find a path from a start state to a goal state.

  • Uninformed search (no hints): breadth-first, depth-first, uniform-cost.
  • Informed search (uses a heuristic estimate h of the distance to the goal): greedy best-first, A* (f = g + h, where g is the cost so far; optimal if h never overestimates).
  • Local search / optimisation: hill climbing (keep moving to a better neighbour; can get stuck on a local peak), simulated annealing, genetic algorithms.

"Greedy algorithm" and "recursive algorithm" are general programming techniques, not AI search methods in the sense this question uses.

Logic in AI

Propositional logic and first-order logic (FOL) are used to represent knowledge and reason. The connectives are ¬ (not), ∧ (and), ∨ (or), → (implies), ↔ (iff); FOL adds the quantifiers ∀ and ∃. A symbol like "<>" is not a standard connective.

A Bayesian network is a graph of random variables with probabilities that captures how they influence each other. A hybrid Bayesian network has both continuous and discrete variables.

Machine learning, in three families

FamilyWhat the data looks likeExamples
SupervisedExamples with correct labelsClassification (spam / not spam) and regression (predict a number). Decision trees, Naive Bayes, SVM, k-NN, linear regression.
UnsupervisedData with no labelsClustering (k-means, hierarchical), dimensionality reduction (PCA)
ReinforcementAn agent acts and receives rewardsQ-learning, SARSA
  • A decision tree asks a series of yes/no questions about the input and can be used for both classification and regression.
  • k-means splits data into k groups by moving k centres to the middle of their closest points. It is a partitional clustering method (as opposed to hierarchical methods that build a tree of merges (agglomerative) or splits (divisive)).
  • PCA reduces the number of features (unsupervised). Naive Bayes is a supervised classifier based on Bayes' theorem.

Typical benefits of AI quoted in exams: spotting business trends to support decisions, helping analyse cyber-security incidents, solving pattern-recognition problems by learning. When all are listed, the answer is "all of the above".
