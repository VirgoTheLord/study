7 · Grammars, Language Classes & Closure

Module B · Theory of computationAsked in 2023 (3 Qs) and 2025 Context-free grammars, the hierarchy of machines, and which operations keep a class closed.

Start here: why finite automata are not enough

A finite automaton can't count. Consider the language {aⁿbⁿ : n ≥ 0} = ε, ab, aabb, aaabbb… To check it you must remember how many a's you saw, and n can be arbitrarily large, but a finite automaton has only a fixed number of states. So this language is not regular. To handle it we need a machine with memory (a stack) and a more powerful way to describe languages (grammars).

Context-free grammars (CFG)

A CFG is a set of rewrite rules (productions). A symbol in capitals is a non-terminal (a placeholder that can be rewritten); lowercase symbols are terminals (the final characters). Starting from the start symbol, you keep replacing non-terminals until only terminals remain. The set of all strings you can produce is the language of the grammar.

Worked example: S → aSb | ε

Start with S. Apply S → aSb: aSb. Apply it again: aaSbb. Finish with S → ε: aabb. The grammar produces ε, ab, aabb, aaabbb, …: exactly {aⁿbⁿ}. The rule works like a counter: each a on the left is matched by a b on the right.

How to work out the language of an unfamiliar grammar

Take S → A | B, A → aAb | c, B → bBd | e. Look at A alone: it wraps a…b around itself, ending in c: so A generates aⁿcbⁿ (c, acb, aacbb, …). Likewise B generates bⁿedⁿ (e, bed, bbedd, …). S picks one of them. To test a given string, ask which family it belongs to. aacbb = a²cb² is in the first family; accbb has two c's and is in neither.

The "which language does this grammar generate?" question (asked in 2023 and 2025)

These questions give a grammar and offer languages such as {aᵐbⁿ : 0 ≤ m ≤ n}, {aᵐbⁿ : 0 ≤ m < n}, {aᵐbⁿ : m < n ≤ …} or {aⁿbⁿ}. Method: (1) find which rule adds an a and a b together (this fixes the "m" part), (2) find which rules add extra b's (or a's) alone, (3) check whether at least one extra is forced.

Example: S → aSb | T and T → bT | b. The first rule adds an a and a b together, giving aᵐ … bᵐ. Then S → T, and T produces one or more b's (T → bT | b always ends with a real b). So every string has m a's and m + (at least 1) b's: the language is {aᵐbⁿ : 0 ≤ m < n}. If instead T could also produce nothing (T → bT | ε), the extra b's could be zero and the language would be {aᵐbⁿ : 0 ≤ m ≤ n}. The whole difference between "<" and "≤" is whether the extra part is forced to be non-empty. Test with the smallest string: is "b" generated? Is "ab"? Is "ε"?

Parse trees, derivations, ambiguity

A derivation is the step-by-step sequence of rewrites. A leftmost derivation always rewrites the leftmost non-terminal first; a rightmost one rewrites the rightmost. A parse tree shows the structure. A grammar is ambiguous if some string has two different parse trees (equivalently two different leftmost derivations). Example: E → E + E | E × E | id. The string id + id × id can be grouped as (id + id) × id or id + (id × id): two parse trees, so the grammar is ambiguous. (Lesson 9 shows how to fix it.)

Decidable means some algorithm always halts with yes/no. Semi-decidable (RE) means an algorithm halts with "yes" when the answer is yes but may run forever when it is no. The halting problem ("does this program ever stop?") is undecidable.

Closure properties

A class is closed under an operation if applying that operation to languages in the class gives a language still in the class. Exams ask "which statement is false/not true?" and the answers come from this table.

Three rules that decide most questions:

1. CFL ∩ regular language = context-free (not necessarily regular). Example: a*b* ∩ {aⁿbⁿ} = {aⁿbⁿ}.

2. If a language and its complement are both recursively enumerable, the language is recursive.

3. Recursive languages are closed under complement; recursively enumerable ones are not.

Telling regular from non-regular

A language is non-regular if recognising it needs unbounded counting or matching: aⁿbⁿ, {ww}, palindromes, strings with equal numbers of a's and b's. The pumping lemma is the formal tool: any long enough string in a regular language has a middle section that can be repeated any number of times and still stay in the language.

Check yourself

ISRO 2023 · Q58

Which of the following statements is NOT true?

The last statement is false: RE languages are not closed under complement. (If they were, then by rule 2 every RE language would be recursive, and the halting problem would be decidable.)
ISRO 2023 · Q59

Which of the following statements is FALSE?

The intersection is context-free, not necessarily regular. Counterexample: a*b* ∩ {aⁿbⁿ} = {aⁿbⁿ}, which is not regular.
