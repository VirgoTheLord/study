24 · Sequential Circuits: Flip-Flops, Registers, Counters

Module G · Digital logicAsked in 2023 and 2025 Circuits with memory.

Start here

A sequential circuit has outputs that depend on both the present inputs and the stored past (its state). The basic memory element holds one bit. Two flavours: a latch responds the whole time its enable (clock) is active (level-sensitive), while a flip-flop changes only at the instant the clock changes (edge-triggered). A clock is a regular 0/1 square wave that tells everything when to update.

The basic memory elements

TypeInputsBehaviour (next state Q⁺)
SRS, RS=0,R=0: hold · S=1,R=0: set Q=1 · S=0,R=1: reset Q=0 · S=1,R=1: forbidden
DDQ⁺ = D (copies D; stores one bit)
JKJ, K00: hold · 01: reset · 10: set · 11: toggle (flip Q)
TTT=0: hold · T=1: toggle

Gated D latch (a D latch with an enable/clock input): while the clock is HIGH the output follows D ("transparent"); when the clock goes LOW the latch holds (stores) the last value. So the statement "when the clock is low, the input passes through to the output" is false.

Registers and shift registers

A register is a group of flip-flops storing a multi-bit word. In a shift register the output of each flip-flop feeds the next, so on each clock pulse the bits move one place. A bit entering an n-bit serial register needs n clock periods to come out the other end, so the delay is n × clock period.

Worked example (2023 question)

8-bit serial register, clock 400 MHz. Clock period = 1 ÷ 400 MHz = 2.5 ns. Delay = 8 × 2.5 ns = 20 ns.

Counters

A counter steps through a sequence of states on each clock pulse. A MOD-N counter has N states (a MOD-16 counter counts 0000 to 1111, then wraps to 0000). A 4-bit binary counter is MOD-16 (2⁴).

  • Asynchronous (ripple) counter: the clock drives only the first flip-flop; each later flip-flop is clocked by the output of the one before it. Simple, but delays add up ("ripples").
  • Synchronous counter: all flip-flops share the same clock, so it is faster.
  • Up counter counts up; down counter counts down; MOD-N is built by resetting at N.
Worked example (2025 question): pulses to reach 0000

A MOD-16 up-counter is at 1001 (decimal 9). Each pulse adds 1: 10, 11, 12, 13, 14, 15, then the next pulse wraps to 0. Pulses needed = 16 − 9 = 7.

Check yourself

ISRO 2025 · Q53

A MOD-16 ripple counter using J-K flip-flops has a current state 1001. How many clock pulses are required to get the state 0000?

Counting up from 9: 10, 11, 12, 13, 14, 15, 0 → 7 pulses.
