25 · Number Systems & Computer Arithmetic

Module G · Digital logicAsked in 2025 Binary, octal, hex, fractions, negative numbers, 2's complement.

Start here

We count in base 10: each position is worth 10 times the one to its right. Computers use base 2 (binary): each position is worth 2 times the one to its right. Position values from the right: 1, 2, 4, 8, 16, 32, 64, 128…

Binary → decimal

1101₂ = 1×8 + 1×4 + 0×2 + 1×1 = 13.

Decimal → binary (divide by 2, read remainders upward)

13 ÷ 2 = 6 r 1; 6 ÷ 2 = 3 r 0; 3 ÷ 2 = 1 r 1; 1 ÷ 2 = 0 r 1. Read bottom to top: 1101.

Octal and hexadecimal

Group bits to shorten them. Octal (base 8): 3 bits per digit. Hexadecimal (base 16): 4 bits per digit, using 0–9 then A=10, B=11, C=12, D=13, E=14, F=15. Example: 1011 1110₂ = B E = 0xBE = 190.

Fractions

After the binary point the position values are ½, ¼, ⅛, 1/16, 1/32…

Worked example (2025 question)

(0.11101)₂ = ½ + ¼ + ⅛ + 0/16 + 1/32 = 0.5 + 0.25 + 0.125 + 0.03125 = 0.90625. In the form 0.90xy5, the digits after 0.90 are 6, 2, 5, so x = 6, y = 2.

Decimal fraction → binary: multiply the fraction by 2 repeatedly and record the integer part each time. 0.625 × 2 = 1.25 (1); 0.25 × 2 = 0.5 (0); 0.5 × 2 = 1.0 (1). So 0.625 = 0.101₂.

Negative numbers: two's complement

Computers need a way to store negative numbers using the same adder circuits. The standard is two's complement with a fixed number of bits n:

  • The leftmost bit is the sign (0 = positive, 1 = negative).
  • To get −x: invert all bits of x, then add 1.
  • Range with n bits: −2ⁿ⁻¹ to +2ⁿ⁻¹ − 1 (8 bits: −128 to +127).
  • Subtraction becomes addition: A − B = A + (two's complement of B).
Worked example: what is 11111010?

The leading 1 says it is negative. Invert: 00000101. Add 1: 00000110 = 6. So 11111010 = −6.

Worked example (2025 question): the product of A = 11111010 and B = 00001010 in 2's complement
  1. A = −6 (shown above). B = 00001010 = 10.
  2. Product = −60.
  3. Write 60 in 8 bits: 00111100. Invert: 11000011. Add 1: 11000100.

(Check: 11000100 negative; invert 00111011, add 1 → 00111100 = 60, so it is −60 ✓.)

Other representations

  • Sign-magnitude: first bit is the sign, the rest is the size (has both +0 and −0).
  • One's complement: invert all bits (also has two zeros).
  • Overflow in two's complement addition happens when two numbers of the same sign give a result of the opposite sign.
  • Floating point (IEEE 754): a number is stored as sign, exponent and mantissa. Single precision: 1 + 8 + 23 = 32 bits; double: 1 + 11 + 52 = 64 bits.
