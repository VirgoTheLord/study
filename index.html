ISRO Scientist/Engineer 'SC' (Computer Science): the course

33 short lessons that start from zero. Built from the topics in the 2023 and 2025 ISRO papers in this folder.

How each lesson works. It starts with what the topic is and why it exists, then explains the ideas in small steps with worked examples and diagrams, and ends with real past-paper questions (and a few practice ones I wrote, marked as such). Try each question before you click the answer. Go in order: later lessons lean on earlier ones (for example, graph algorithms use trees, and the network lessons build on each other).

How to cover the course

  1. Go module by module, in order. A → K. Dependencies matter: Boolean algebra (G) comes before computer organization; the four network lessons (D) build on each other; the compiler lessons (B) lean on grammars and automata.
  2. One lesson, one sitting. Read it through once without stopping to memorise. Then do the questions at the end before clicking the answers. A wrong answer is useful: it shows exactly which idea didn't stick.
  3. Work the examples with pen and paper. The numeric topics (scheduling, Banker's algorithm, page replacement, subnetting, window size, RSA, K-maps, 2's complement) are learned by doing, not reading. Cover the solution and redo it.
  4. Two kinds of topic, two ways of studying. Calculation topics (lessons 5, 10–12, 14–16, 20, 22–25, 27–28, 31): practise the method until it is automatic. Vocabulary topics (lessons 8, 13, 17–18, 21, 29–30): the questions are mostly "which term matches this description", so learn each term with its one-line hook and revisit the list a day later.
  5. Where the marks were. Across the two papers, Operating Systems, Networks, Databases, Digital Logic and Architecture, and Security each had many questions; AI, Big Data and Cloud jumped to about 15 of 80 in 2025 and is mostly one-fact questions. If you must prioritise, don't skip these.
  6. Review in layers. When a module is done, redo the questions you missed. After finishing everything, use the one-page fact sheet at the bottom to test yourself, and go back to the lesson for anything you can't explain in your own words.
  7. Ask when stuck. If a step doesn't make sense, ask me, and I can re-explain it differently or give more practice questions on that topic.

Honest limits. (1) Answers were worked out by hand and checked with code where numeric; I did not have the official answer key. (2) Questions that depended on a figure (graphs, circuits, state diagrams) did not extract from the PDFs, so I skipped them and wrote practice questions of the same kind. (3) Book references are named but their links were not checked. (4) The course covers the topics that appeared in the 2023 and 2025 papers. A different year may ask something outside them, so treat this as strong coverage of what has been asked, not a guarantee of the whole syllabus.
